# Kalender Jalur Prestasi PTN 2026–2027

Website ini berisi kalender interaktif untuk jalur prestasi, talent scouting, rapor, dan SNBP PTN Indonesia tahun 2026–2027.

Halaman dibuat agar mudah dipakai untuk:
- melihat jadwal pendaftaran, deadline, dan pengumuman,
- mencari kampus atau jalur tertentu,
- memfilter berdasarkan jenis seleksi,
- melihat statistik ringkas jadwal,
- membuka tautan resmi masing-masing kampus dan seleksi.

## Fitur

- Tampilan UI/UX modern dan responsif
- Pencarian kampus atau jalur
- Filter jalur seleksi
- Toggle tampilan prediksi 2027
- Chip filter kampus
- Tautan resmi ke halaman admission masing-masing kampus
- Statistik ringkas jadwal

## Isi Data

Data yang ditampilkan mencakup:
- nama kampus,
- nama jalur/event,
- tanggal buka pendaftaran,
- deadline,
- tanggal pengumuman,
- peringkat Indonesia,
- peringkat dunia,
- catatan singkat.

## Catatan

Website ini dibuat untuk membantu perencanaan jalur prestasi PTN secara visual dan mudah dibaca.
Semua tautan resmi tetap mengarah ke sumber aslinya.
